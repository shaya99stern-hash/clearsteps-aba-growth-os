# Clear Steps — Active Product Contract

Clear Steps is an evidence-first ABA territory-intelligence, referral-growth, recruiting, outreach, and CRM operating system.

## Current implementation target

The first implementation slice must work without paid API keys and must provide:

- Node/Next.js orchestration
- public web discovery
- direct public-site enrichment
- source-purpose registry (`discover`, `enrich`, `verify`, `monitor`)
- area-level community demand signals
- territory scoring
- evidence-backed lead dossiers
- referral/talent CRM save and stage progression
- no demo leads
- no household disability targeting

## Non-negotiable boundaries

- Public community discussions are aggregated as territory signals.
- No parent/child dossiers and no household-level disability inference.
- No private group scraping or login bypassing.
- Verification-only registries are not recruiting lists.
- Source provenance and unknowns stay visible in the UI.
